# Design sync notes

- This repo is a native SwiftUI app with no web components, so the sync is **tokens only**: `ds-bundle/styles.css` + `ds-bundle/tokens/*.css`, a README built from `conventions.md`, and a swatch page at `ds-bundle/guidelines/tokens.html`. There is no `_ds_bundle.js` (the app generates a stub) and no `_ds_sync.json` anchor; the only cards are the four token cards below, so every sync re-uploads everything.
- `ds-bundle/` is hand-authored, not generated by the converter, and is committed. When a color in `NotesAnxiety/Assets.xcassets` changes, update `ds-bundle/tokens/colors.css` by hand and regenerate the README token index (`conventions.md` + list of `--*` names per token file).
- The source of truth is the **app** asset catalog. The widget catalog (`NotesWidget/Assets.xcassets`) was re-synced to match it on 2026-10-22; every shared colorset is identical except `AccentColor` (the widget's uses the system default).
- The asset named `Black` is actually off-white `#FEFFFF`.
- `WidgetBackground` and the widget's `AccentColor` use system colors, so they are not exported.
- Typography sizes are the iOS Dynamic Type defaults (Large). SF Pro is not uploaded (license); it resolves via `-apple-system`.
- The Design System pane only shows **cards**: HTML files at `components/<group>/<Name>/<Name>.html` whose first line is `<!-- @dsCard group="…" viewport="WxH" -->`. Tokens alone register in `_ds_manifest.json` but leave the pane empty. `.design-sync/make-cards.py` regenerates the four token cards (Brand/AnxietyLevels, Colors/Palette, Type/Typography, Spacing/RadiusAndSpacing) and the `_ds_needs_recompile` sentinel, which must contain `{"by": "design-sync-cli"}`. Re-run it after editing `ds-bundle/tokens/*.css`, then upload `components/**` with the rest.
- `[data-theme="dark"]` works on any element (not just `<html>`), so a subtree can render dark; the cards use this for side-by-side light/dark.
