# Design sync notes

- This repo is a native SwiftUI app with no web components, so the sync is **tokens only**: `ds-bundle/styles.css` + `ds-bundle/tokens/*.css`, a README built from `conventions.md`, and a swatch page at `ds-bundle/guidelines/tokens.html`. There is no `_ds_bundle.js`, there are no component cards and there is no `_ds_sync.json` anchor, so every sync re-uploads everything.
- `ds-bundle/` is hand-authored, not generated by the converter, and is committed. When a color in `NotesAnxiety/Assets.xcassets` changes, update `ds-bundle/tokens/colors.css` by hand and regenerate the README token index (`conventions.md` + list of `--*` names per token file).
- The source of truth is the **app** asset catalog. The widget catalog (`NotesWidget/Assets.xcassets`) has drifted: `SystemMinimal/Mild/Moderate/Severe` there are the blue Cards-style palette with dark variants (app: teal/blue `#04BADE`, `#0496C7`, `#006CA5`, `#015480`, no dark variant), and `BackgroundSecondary` is `#F4F4F4`/`#383838` (app: `#383838` only). AGENTS.md says the two catalogs should match.
- The asset named `Black` is actually off-white `#FEFFFF`.
- `WidgetBackground` and the widget's `AccentColor` use system colors, so they are not exported.
- Typography sizes are the iOS Dynamic Type defaults (Large). SF Pro is not uploaded (license); it resolves via `-apple-system`.
